iGhostVT 1.6.35 lets `ighostvt-cli` open a session in the app, and set up a new session the way you want it.

- A session made with `ighostvt-cli new` had no tab until the app was next launched. `ighostvt-cli app attach <sid>` now brings it up in the running app, opening a tab for it if no window has one, and `new --attach` does the same as soon as the session starts.
- `ighostvt-cli new` always started the shell at 80×24 in your home folder. It now takes `--cols` and `--rows` (or `--size 120x40`), `--cwd`, `--cwd-of <sid>` to start where another session's shell is, `--env NAME=VALUE`, `--shell`, and `--lock interaction` or `--lock keyboard`. All but `--attach` work with `--host` too.

Choose `iphoneos-arm64e` for roothide, `iphoneos-arm64` for a rootless bootstrap, `iGhostVT-1.6.35-macos-notarized.zip` for a Mac — it is signed and notarized, so it opens without clearing quarantine, and updates itself — or `GhostRemote-1.6.35.ipa` for an iPhone or iPad without custom firmware, which your sideloading app signs as it installs it. To run the relay, use the attached `compose.yml`; the image is `ghcr.io/owngoal-dev/ighostvt-relay`, and the digest is in `relay-image.txt`. SHA-256 sums are in `SHA256SUMS`, and the Mac app's in `SHA256SUMS.macos`.
