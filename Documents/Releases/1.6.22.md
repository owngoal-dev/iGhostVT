iGhostVT 1.6.22 brings a terminal back exactly as it was when you reopen it or a connection drops.

- After `sz` or `rz`, opening iGhostVT again could fill the terminal with symbols. The transfer is now left out of what the terminal shows when it comes back, however long ago it ran and however large the file was.
- A program still running when you came back — vim, htop, Claude Code — could stop getting taps, scrolling, pasted text or modified keys as it expects, or drop off the full screen it was using. Everything the program set up is now put back before its output is shown again.
- Coming back could type stray text such as `^[[?62;22c` into a shell or a program: the terminal answered old questions in the output again. It no longer does, and no longer repeats a clipboard copy or a notification from earlier output either.
- The output shown on coming back no longer starts with a fragment of a control sequence or half a character.
- When a connection drops and comes back — to a paired device, or after iOS paused iGhostVT long enough to lose it — the terminal now carries on from where it stopped, with no gap and nothing printed twice, as long as the device still holds what it missed (with a paired device, once both run 1.6.22); after more than that, it is brought back as on reopening. A line saying the connection was lost is no longer written into the terminal while it reconnects; "Connecting…" shows over it instead.
- A flood of output that the terminal cannot keep up with is now held back until it catches up, instead of losing its oldest part.

Choose `iphoneos-arm64e` for roothide, `iphoneos-arm64` for a rootless bootstrap, `iGhostVT-1.6.22-macos-notarized.zip` for a Mac — it is signed and notarized, so it opens without clearing quarantine, and updates itself — or `GhostRemote-1.6.22.ipa` for an iPhone or iPad without custom firmware, which your sideloading app signs as it installs it. To run the relay, use the attached `compose.yml`; the image is `ghcr.io/owngoal-dev/ighostvt-relay`, and the digest is in `relay-image.txt`. SHA-256 sums are in `SHA256SUMS`, and the Mac app's in `SHA256SUMS.macos`.
