iGhostVT 1.0.2 confirms every copy, drops the New Window item that could not open a window on iPhone, and lets you add your own Ghostty settings.

- Copy Text and Copy as Image in a tab's menu worked but showed nothing, so they looked broken. A "Copied" confirmation now appears at the top of the window.
- On iPhone, the ⋯ menu offered New Window, which did nothing because a phone runs one window. It is gone from that menu, and New Window and Close Window no longer appear in Settings ▸ Keyboard ▸ Shortcuts there.
- The configuration shown in Settings ▸ Advanced could be read but not changed. A Custom Configuration field above it now takes your own Ghostty `key = value` lines, applied after everything the app generates, so they also override the theme. New tabs use them.
- Tapping Copy on that configuration changed the button's label, and the whole section shifted by a few points. The button now stays the same and the same "Copied" confirmation appears.

Choose `iphoneos-arm64e` for roothide, `iphoneos-arm64` for a rootless bootstrap, `xros-arm64e` for a jailbroken Apple Vision Pro, or `iGhostVT-1.0.2-macos.zip` for a Mac — the Mac app is ad-hoc signed, so clear its quarantine once with `xattr -dr com.apple.quarantine /Applications/iGhostVT.app`. SHA-256 sums are in `SHA256SUMS`, and the Mac app's in `SHA256SUMS.macos`.
