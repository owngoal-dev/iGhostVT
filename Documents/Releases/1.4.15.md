iGhostVT 1.4.15 copies text without the padding programs draw around it, takes a terminal back when you return to the app, and holds a file dropped on a tab that is still connecting until it can send it; it connects to devices on any 1.4 release.

- Copying a paragraph out of a program that lays out its own lines, such as Claude Code, brought along the spaces it paints at the end of each row and the indent at the start of the next. A copy now leaves them out, whether the text was selected by touch or with the pointer, and the selection highlight covers only the text. Indentation relative to where the selection starts is kept, so copied code still lines up.
- Coming back to the app could show "In Use on" another device and wait for Use Here. The first time you look at a tab after returning, it now takes the terminal back by itself; a device that takes it again while you are here still gets the card, so two devices never pass a terminal back and forth on their own.
- Closing a remote tab that another device is using asked whether to end the session. It now closes at once and leaves the terminal running.
- A file dropped on a remote tab while it was connecting was lost. The transfer now appears straight away, waits for the connection, then sends the file and pastes its path; it can be cancelled while it waits.
- Closing a remote tab asked with one filled answer and one outlined. Detach Session and Terminate Session are now both filled, and Return still detaches.
- A device's open terminals in the new-tab menu each carried the program's name under the title, the same for every agent. They now show the title alone, and a device with more than three leads with Open All, which opens every one not already open here.
- A remote tab's name wore a globe. It is now marked by a highlight under the title, as Fila marks the folder you are in.

Choose `iphoneos-arm64e` for roothide, `iphoneos-arm64` for a rootless bootstrap, `iGhostVT-1.4.15-macos-notarized.zip` for a Mac — it is signed and notarized, so it opens without clearing quarantine — or `GhostRemote-1.4.15.ipa` for an iPhone or iPad without custom firmware, which your sideloading app signs as it installs it. To run the relay, use the attached `compose.yml`; the image is `ghcr.io/owngoal-dev/ighostvt-relay`, and the digest is in `relay-image.txt`. SHA-256 sums are in `SHA256SUMS`, and the Mac app's in `SHA256SUMS.macos`.
