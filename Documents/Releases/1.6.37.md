iGhostVT 1.6.37 adds an MCP server so AI apps on the same device, such as FlowDown, can run commands and use their own terminal sessions once you allow them.

- An AI app on your iPhone, iPad or Mac had no way to use iGhostVT's terminals. Turn on MCP Server in Settings ▸ Advanced (on a Mac, in the Advanced pane of the Settings window), then add `http://127.0.0.1:18765/mcp` to the app as an MCP server. The app can then run commands, and open, read and type into terminal sessions it opens itself.
- An app can connect only after you allow it in iGhostVT. When it asks, iGhostVT shows its name and a six-digit code; allow it only if the app's sign-in page shows the same code. Prompts appear only while that Settings page is open, so nothing can ask in the background, and Forget Authorized Apps removes every app you allowed. The server is off by default, accepts connections only from the same device, and is not included in Ghost Remote.

Choose `iphoneos-arm64e` for roothide, `iphoneos-arm64` for a rootless bootstrap, `iGhostVT-1.6.37-macos-notarized.zip` for a Mac — it is signed and notarized, so it opens without clearing quarantine, and updates itself — or `GhostRemote-1.6.37.ipa` for an iPhone or iPad without custom firmware, which your sideloading app signs as it installs it. To run the relay, use the attached `compose.yml`; the image is `ghcr.io/owngoal-dev/ighostvt-relay`, and the digest is in `relay-image.txt`. SHA-256 sums are in `SHA256SUMS`, and the Mac app's in `SHA256SUMS.macos`.
