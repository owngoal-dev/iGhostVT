iGhostVT 1.0.1 turns every `+` into a menu: a new terminal now opens where you say — the home, wherever another tab is, or a directory you were in before.

- Opening a terminal somewhere other than the current tab's directory meant opening one and typing `cd`. New Tab now lists the home, the directories this window's tabs are in, and the ones your sessions have been in before, in three groups, each sorted and none repeating another. ⌘T is unchanged and still opens where the current tab is, and until there is more than the home to choose from the control stays the plain `+` it was.
- On iPhone with tabs open there is no `+` on screen at all, so the same choice sits under the ⋯ menu's New Tab.
- The app had no way of knowing where a shell was unless that shell reported it, so `sh` and anything without shell integration had no directory at all. The terminal helper now reads it from the kernel and says when it changes — including a `cd` typed at a prompt, which starts no program and was invisible before. The Live Activity shows the directory for those sessions too.
- Settings ▸ Advanced ▸ Recent Directories: turn the remembered list off (which also stops it being recorded), sort it by last visited or most visited, or clear it.
- `ighostvt-cli list` printed a session's directory as the kernel spells it, which under roothide is a path through a randomly named jbroot that no shell ever shows. It prints `~` for the home and `@jb/…` for the rest of the bootstrap now, as does the new menu.
- Advanced's Shell and Sort By rows carried an icon the sections below them did not; the form reads as one list again.

Choose `iphoneos-arm64e` for roothide, `iphoneos-arm64` for a rootless bootstrap, `xros-arm64e` for a jailbroken Apple Vision Pro, or `iGhostVT-1.0.1-macos.zip` for a Mac — the Mac app is ad-hoc signed, so clear its quarantine once with `xattr -dr com.apple.quarantine /Applications/iGhostVT.app`. SHA-256 sums are in `SHA256SUMS`, and the Mac app's in `SHA256SUMS.macos`.
